鉴于 · Recitals
A. 甲方基于商米 POS 终端硬件签名技术，发起 Real-World Assets（"RWA"）发行平台试点项目（"本项目"）。一期面向新加坡市场，向合格投资人发行 6 个月期短期债务凭证。
B. 甲方董事长邀请乙方担任本项目的项目负责人，全面负责本项目从技术验证、数据价值验证至首笔 RWA 发行的执行交付。
C. 为明确双方在本项目中的权利义务、预算安排、决策机制、报酬结构与责任边界，双方经友好协商，达成本协议。
第 1 条

项目定义与目标

1.1 项目名称：商米 RWA 平台一期试点。

1.2 试点地点：新加坡 Jurong Point（一期单店），具体商户由双方共同确认。

1.3 项目目标：在约 12 周内完成以下三阶段交付，达成首笔 RWA 链上发行：

(a) Phase 0 · 技术可行性确认（Week 1）：商米 POS SDK 可用性评估，得出 Go / No-Go / 暂停 三种结论之一。
(b) Phase 1 · 数据价值验证（Week 2–8）：系统上线运行，运营 30 天，由 ANext（或同等持牌方）确认数据价值，商家获得贷款。
(c) Phase 2 · 首笔 RWA 发行（Week 5–12，与 Phase 1 并行）：通过持牌方完成链上发行，商家收到融资款。
第 2 条

乙方角色与职责

2.1 角色：乙方担任本项目的项目负责人，直接向甲方董事长汇报。

2.2 主要职责包括但不限于：

  • 整体架构设计与项目推进；
  • 外部合规顾问 / 律师事务所（包括但不限于 Davis Polk）的选聘、对接与协调；
  • 持牌方（如 ANext）的接入与合规通道搭建；
  • 试点商户的尽职调查、签约与现场对接；
  • 甲方内部技术、品牌、商务团队的协调；
  • 智能合约开发与外部审计（SlowMist / CertiK / Hacken 等）的发包与验收；
  • 项目预算的管理、使用与定期汇报；
  • Go / No-Go 决策点的材料准备与提交。

2.3 投入程度：乙方承诺在本项目期间投入 不少于 80% / 全职 工作时间。

第 3 条

时间安排与里程碑

本项目自协议签署之日起算，整体周期约 12 周（3 个月）。关键里程碑如下：

M1 Phase 0 完成（Week 1）：SDK 评估报告交付 + Go-1 决策点。
M2 Phase 1 完成（Week 8）：可信经营报告系统上线运营 30 天 + ANext 数据价值认可意见 + 商家贷款落地 + Go-2 决策点。
M3 Phase 2 完成（Week 12）：首笔 RWA 链上发行完成 + 商家收到融资款 + 最终验收。

3.4 延期处理：任一阶段延期超过 2 周 时，双方应在 5 个工作日 内协商：(a) 延期方案、(b) 范围调整、或 (c) 终止协议三种处理路径之一。

第 4 条

项目预算

4.1 总预算：本项目总预算为 SGD 167,000（约 USD 125,000），具体明细见附表 A。本预算仅覆盖乙方负责执行的技术、产品、合规对接与项目管理工作；持牌方通道费用（如 ANext / 同等持牌发行方的发行通道费、KYC / AML / MAS 备案 / 资产结构通道费等）由甲方另行直接承担，不在本协议预算范围内。

4.2 预算构成：

  • 开发：SGD 100,000
  • 合规（数据授权 + 商米合作 + 法律顾问）：SGD 12,000
  • 审计：SGD 22,000
  • 杂项（含应急储备）：SGD 33,000

4.3 应急储备：预算中已含各阶段 10% 应急储备，使用须经甲方书面批准。

4.4 超支处理：单项开支超出预算项 10% 或合计超支 SGD 20,000 时，须事先获甲方书面同意。

4.5 货币与汇率：本项目记账与结算货币为 SGD；如需以其他货币支付，按支付日银行中间价折算。

第 5 条

拨付安排与 Go / No-Go 决策

5.1 分批拨付：预算分两批拨付至项目专用账户：

批次触发条件 / 覆盖范围金额 (SGD)
第一批 项目启动 · 覆盖 Phase 0 + Phase 1（技术验证 → 数据价值验证）
拨付时点：协议签署后 5 个工作日内 86,000
第二批 Phase 1 达成 · 覆盖 Phase 2（链上开发 + 智能合约 + 审计 + Phase 2 应急储备）
拨付时点：Go-2 通过后 10 个工作日内 81,000

5.2 Go / No-Go 决策点：

Go-1 Phase 0 → Phase 1：判定标准为商米 POS SDK 可用性、采集层可工程化。乙方提交评估报告，甲方在 5 个工作日 内书面答复 Go / No-Go / 暂停。详细判定见附表 C。
Go-2 Phase 1 → Phase 2：判定标准为 (a) 系统稳定运营 30 天、(b) ANext 出具数据价值认可意见、(c) 商家完成贷款落地。乙方提交阶段交付物，甲方在 10 个工作日 内书面答复 Go / No-Go。详细判定见附表 C。

5.3 No-Go 后果：若 Go-1 或 Go-2 任一决策点未通过，第二批拨付不发生；已支付的第一批资金按附表 C 结算原则处理。

第 7 条

预算管理权与开支

7.1 开支权限：乙方有权按附表 A 的预算明细动用资金，包括对外发包、签约第三方供应商、聘用项目临时人员。

7.2 单项审批阈值：单项支出超过 SGD 20,000，或单一对外合同金额超过 SGD 50,000 的，须事先获甲方书面批准。

7.3 定期报告：乙方应于每月 第 5 个工作日 之前向甲方提交上月资金使用报告，含发票存档与实际开支明细。

7.4 资金账户：本项目资金存放于乙方在 银行 / 地区 开立的项目专用账户，账户信息向甲方备案。

7.5 持牌方通道费用：第 4.1 条所述的持牌方通道费用，由甲方按持牌方实际报价直接支付，不经由乙方账户流转。乙方负责协调持牌方对接，但不承担该项费用的预算管理责任。

第 8 条

决策权与汇报机制

8.1 乙方决策权：在项目执行层面，乙方对以下事项有完整决策权：

  • 项目内部人员安排与团队组建；
  • 预算项内的开支决策（受第 7.2 条约束）；
  • 非重大第三方供应商的选择。

8.2 甲方批准事项：以下事项须乙方提请、甲方书面批准：

  • 合作律师事务所的最终选定（包括 Davis Polk 聘用书签署）；
  • SPV 主体设立及股权结构；
  • 持牌发行通道方（如 ANext）的最终选定；
  • 试点商户的最终确认与签约；
  • 智能合约审计方的选定；
  • 对外宣传、媒体披露材料的发布。

8.3 汇报机制：

  • 周报：每周 周五 提交书面周报；
  • 月度会议：每月召开 1 次进度评审会；
  • 里程碑评审：每阶段结束时召开正式 Go / No-Go 评审。
第 9 条

知识产权

9.1 甲方既有权利：商米品牌、POS 硬件 IP、设备密钥根证、商户数据采集体系等甲方既有 IP 仍由甲方独占享有，本协议不作任何转让。

9.2 项目期间产生的 IP：本项目期间，由乙方或乙方组织的团队为本项目专门开发的产品逻辑、流程、设计、文档、代码等成果，IP 归属约定如下：

(a) 与商米 POS 数据采集 / 硬件签名直接绑定的实现：归甲方所有。
(b) RWA 发行业务逻辑 / 投资人交互流程 / 合规结构设计：归甲方 / 共有 / 归乙方（请双方协商）。
(c) 乙方独立开发并在本项目前已存在的方法论与工具：仍归乙方所有；乙方在本项目期间授予甲方非独占、不可转让的使用许可。

9.3 第三方 IP：项目期间委托第三方（如智能合约开发、审计）产生的 IP 归属，由各自的发包合同约定，原则上交付物归甲方所有。

第 10 条

保密义务

10.1 双方相互对在项目期间获得的对方非公开信息、商业秘密、技术资料、商户信息、投资人信息承担保密义务。

10.2 例外：不构成保密义务的信息包括：(a) 已经公开的信息；(b) 接收方在接收前已合法持有的信息；(c) 经对方书面同意公开的信息；(d) 根据法律或监管要求必须披露的信息。

10.3 期限：保密义务自协议签署之日起持续至本协议终止后 3 年。

第 11 条

排他性与竞业限制

11.1 项目期间：乙方不得直接或间接为任何与本项目构成实质竞争关系的第三方提供同类 RWA 项目咨询或负责人服务。

11.2 项目结束后：项目正式终止之日起 6 个月 内，乙方不得接受由本项目商户、持牌方或律所发起的与本项目高度竞争的同类委托，除非获甲方书面同意。

11.3 本条不限制乙方在不冲突领域的其他业务活动。

第 12 条

协议终止与结算

12.1 甲方单方终止权：以下情形之一，甲方可书面通知乙方终止本协议：

  • Go-1 或 Go-2 判定为 No-Go；
  • 乙方严重违反本协议且经书面通知 15 个工作日 内未予纠正；
  • 乙方失能或丧失承担本项目的能力。

12.2 乙方单方终止权：甲方逾期支付应付款项 30 天 以上，或单方实质性变更项目目标导致乙方无法继续履行，乙方可终止本协议。

12.3 结算原则：协议终止时：

(a) 已发生且已批准的预算开支：由甲方承担；
(b) 乙方按比例享有截至终止日的月度管理费；
(c) 已完成阶段的里程碑奖金按已通过的 Go 决策点结算；
(d) 成功费、长期分润：仅在完成对应触发条件时支付，否则不予支付。

12.4 不可抗力：因不可抗力（包括但不限于监管政策重大变化）导致项目无法继续，双方协商终止，未发生但已承诺的款项不再支付。

第 13 条

责任与责任限制

13.1 乙方尽职义务：乙方应以专业、勤勉、谨慎的方式履行本协议项下职责。

13.2 不构成兑付担保：乙方的角色为项目执行负责人，不构成对 RWA 发行后投资人本金及收益的任何担保或兜底。投资人对发行人（SPV / 商户）的追索权利不延伸至乙方。

13.3 责任限额：除故意或重大过失外，乙方因履行本协议产生的责任上限不超过 乙方已收取报酬总额的 100%。

第 14 条

适用法律与争议解决

14.1 适用法律：本协议适用 新加坡 / 香港 / 中国大陆 法律（请双方协商确定）。

14.2 争议解决：因本协议引起的争议，双方应首先友好协商；协商不成的，提交 新加坡国际仲裁中心（SIAC）/ 香港国际仲裁中心（HKIAC） 按届时有效的仲裁规则仲裁。仲裁地：新加坡 / 香港。仲裁语言：中文。仲裁裁决终局。

第 15 条

一般条款

15.2 完整协议：本协议（含附表 A / B / C 及双方另行单独签订的报酬附表）构成双方就本项目的完整协议。

附表 C

Go / No-Go 决策标准

Go-1（Phase 0 → Phase 1）

  • Go：商米 POS SDK 可获取每笔交易的硬件签名 + 关键字段可读取（金额、时间、SKU、设备 ID）+ 签名可上链验证。
  • 暂停：SDK 部分可用但需商米侧补充开发；明确补充范围与时间表。
  • No-Go：SDK 不具备硬件签名能力 / 采集层不可工程化。

Go-2（Phase 1 → Phase 2）

  • Go：同时满足以下条件：(a) 系统上线运营 ≥ 30 日且 SLA 达标；(b) ANext 或同等持牌方出具数据价值认可意见；(c) 商家完成贷款落地；(d) 无重大合规或技术风险。
  • No-Go：以上任一条件未达成且无可补救路径。

No-Go 后的资金结算

  • 已发生且已批准的预算开支：由甲方承担，已支付部分不退还；
  • 剩余未使用资金：在 No-Go 决定后 15 个工作日 内退还至甲方指定账户；
  • 乙方按比例享有截至 No-Go 日的月度管理费；
  • 已通过阶段的里程碑奖金按第 12.3 条结算。
